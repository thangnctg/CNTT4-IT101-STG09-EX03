# Bao cao bai tap Markdown

## I. Phan tich Input va Output

-   **Input (Text tho):** La chuoi ky tu nguon chua cac cu phap Markdown như `, ```, |, *, [\ ]. Git va cac trinh quan ly ma nguon se doc va so sanh (diff) truc tiep tren cac chuoi text nay.
    
-   **Output (Rendered UI):** La giao dien duoc StackEdit/GitHub bien dich ra visual trực quan: co mau cho code (syntax highlighting), bang bieu co duong ke ngan nap va o tick box chon duoc.
    

## II. Noi dung huong dan (.md)

Markdown

```
# Huong dan cai dat va cau hinh VS Code

## 1. Lenh co ban
Khai bao bien `user_name` va `api_key` trong file cau hinh.
Su dung ky tu \* de ghi chu va \# de comment trong file plaintext (dung escape `\` de khong bi render thanh định dạng Markdown).

## 2. Doan code Python mau
```python
def check_installation(status):
    user_name = "PTIT_Student"
    if status == True:
        print(f"Chuc mừng {user_name} da cai dat thanh cong!")
    else:
        print("Cai dat thất bại, vui long kiem tra lai.")

check_installation(True)

```
